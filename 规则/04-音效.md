## 〇、优先级（阿亮 2026-10-24，10-29 再次确认）

> 「以后最优先级用 earshot 里面的音效，没有合适的再去 openverse 挑最合适的匹配到视频里。」

找音效按这个顺序，前一步有合适的就不往下走：

1. **earshot 音效库**（<https://github.com/Leonxlnx/earshot>）：252 个用代码渲染的音效，见下面「earshot 怎么用」。
2. **Openverse**：搜最匹配画面动作的那个，来源只勾 Freesound（见「一、去哪找」）。以前挑好的备用音效见「五」的表，用 `工具/openverse.py get 编号 文件名` 重新下载。
3. 哔声、雪花这类纯信号音，ffmpeg 自己合成。

「合适」的标准：动作对得上（见「三」的表）、试听不出戏。earshot 里没有这一类声音（唱片刮擦、滑哨、收银机、撞车、蜂鸣器等），或者试听后不如网站上的贴切，就往下一步走。每期用了哪个 earshot 音效、哪些动作退回到网站，在交付时跟阿亮说明。

### earshot 怎么用

- 安装在阿亮的 Mac 上：`~/earshot`（MCP 服务器名 `earshot`，Claude Code 里可直接调 `sfx_list`、`sfx_render`、`kit_render`）。安装踩坑见 [08-踩坑记录](08-踩坑记录.md)。
- **云端环境也能直接渲染**：`sfx` 和 `kit` 不加载模型、不联网，不用装 torch（2026-10-24 实测）。
  ```bash
  git clone --depth 1 https://github.com/Leonxlnx/earshot ext/earshot
  python3 -m venv es && es/bin/pip install numpy scipy soundfile soxr librosa pyloudnorm scikit-learn pillow matplotlib
  es/bin/pip install --no-deps -e ext/earshot
  ```
- 常用命令：
  ```bash
  earshot sfx list --kind whoosh                         # 按类型列出 id、时长、峰值位置、可调参数
  earshot sfx render ui_pop/soft -o 音效/pop.wav          # 渲染一个
  earshot sfx render whoosh_fast/crisp -o 音效/w.wav --dur 0.8 --apex 0.32   # 定长 0.8 秒，最响处落在 0.32 秒
  earshot sfx render mallet/glock -o 音效/g.wav --pitch E5                   # 有音高的可以调到和 BGM 同调
  earshot sfx check 音效/w.wav                           # 检查爆音、截断、削波
  ```
- **用 `--dur` 代替手动截短，用 `--apex` 把 whoosh 最响的一下对准画面动作**，比截网站素材准（误差 5 ms 以内）。同一个音效连用多次时加 `--seed N` 出不同的 take，听起来不机械。
- 同一 id 在 bank 里有多个成员（如 `ui_pop/soft step boop blip fall wide`），先各渲染一个听，挑最贴的。
- 渲染出来是 wav；`mix.py` 目前只读 `音效/*.mp3`，用 ffmpeg 转一下：`ffmpeg -i x.wav -b:a 192k x.mp3`。
- 当期 `音效/来源.md` 里登记成：`文件名 | earshot <id> | seed / 参数 | MIT（代码渲染，无需署名）`。
- 注意 align：0.4 新加的 riser（`riser/dark build snatch`）和 `reverse_swell` 是**先升到顶再回落**，要用 `align='peak'`；老的 riser（`riser/shepard` 等）停在最响处，用 `align='end'`。
- earshot 的其它功能顺手可用：`earshot rank "描述" a.mp3 b.mp3 ...` 在一堆网站下载的候选里按描述排序；`earshot timeline mix.wav --video 成片.mp4` 检查音效是否卡在画面切点上。这两个要加载模型（约 1.1 GB），在 Mac 上跑。

## 一、去哪找（网站，earshot 没有合适的再用）

**从 Openverse 找，来源筛选为 Freesound。**

- 网页：<https://openverse.org/>，搜索后在左侧「Source」里只勾 Freesound，「License」优先 CC0。
  直接打开这个链接就是筛好的：<https://openverse.org/search/audio?q=whoosh&source=freesound&license=cc0>（把 `q=` 后面换成要找的词）
- 接口（脚本用）：`https://api.openverse.org/v1/audio/?q=关键词&source=freesound&license=cc0`
  - 必须带浏览器 User-Agent，否则 403；匿名每页最多 20 条，有频率限制。
  - 返回里 `url` 是 Freesound 的 hq 预览 mp3，`foreign_landing_url` 是原页面（署名用）。
- 命令行工具：[工具/openverse.py](../工具/openverse.py)
  ```bash
  python3 工具/openverse.py search whoosh          # 列候选：编号、时长、许可、作者、标题
  python3 工具/openverse.py get 60007 whoosh_swipe # 下载到 音效/whoosh_swipe.mp3，自动登记到 音效/来源.md
  ```
- **许可**：优先 CC0；CC BY 可以用，但要在视频简介署名。每期在 `音效/来源.md` 记下文件名、原名、作者、许可、链接。
- 以前挑好的 36 个见「五」的表，链接最后一段数字就是编号，可以直接重新下载。

## 四、用法细节

- **音效先峰值归一，再按表里的 dB 放**（`mix.py` 已经这样做），不同素材的原始响度差异不会影响。
- 对齐方式：`start` 开头对齐（默认）；`end` 结尾对齐（riser）；`peak` 最响处对齐（有前摇的重击）。
- 长音效用 `dur` 截短，末尾自动 50 ms 淡出。
- **不要叠太多**：同一时刻最多两层（例如 impact + sparkle）。阿亮那期要求删掉了 18 秒附近一组 riser + hit + lightning，因为太吵、和画面不匹配。
- 同一类动作全片用同一个音效，观众会形成条件反射（焦点切换永远是同一个 whoosh，弹出永远是同一个 pop）。用 earshot 时是「同一个 id、不同 seed」，音色一致又不机械。

### 自制（ffmpeg 合成，无版权问题）

| 文件 | 内容 | 生成命令 |
|---|---|---|
