# 04 音效

来源：阿亮的长期偏好 + DeepSeek 三模型 PK 那期（2026-10，全片 179 个音效）+ 鹈鹕测试重剪（2026-10）。

## 一、去哪找

**默认从 Openverse 找，来源筛选为 Freesound。**

- 网页：<https://openverse.org/>，搜索后在左侧「Source」里只勾 Freesound，「License」优先 CC0。
  直接打开这个链接就是筛好的：<https://openverse.org/search/audio?q=whoosh&source=freesound&license=cc0>（把 `q=` 后面换成要找的词）
- 接口（脚本用）：`https://api.openverse.org/v1/audio/?q=关键词&source=freesound&license=cc0`
  - 必须带浏览器 User-Agent，否则 403；匿名每页最多 20 条，有频率限制。
  - 返回里 `url` 是 Freesound 的 hq 预览 mp3，`foreign_landing_url` 是原页面（署名用）。
- 命令行工具：[工具/openverse.py](../工具/openverse.py)
  ```bash
  python3 工具/openverse.py search whoosh          # 列候选：编号、时长、许可、作者、标题
  python3 工具/openverse.py get 60007 whoosh_swipe # 下载到 音效/whoosh_swipe.mp3，自动登记到 音效/来源.md
  ```
- **许可**：优先 CC0；CC BY 可以用，但要在视频简介署名。每期在 `音效/来源.md` 记下文件名、原名、作者、许可、链接。
- 已经挑好的 38 个在 [音效库/](../音效库/)，先从这里拿，不够再去搜。

## 三、什么动作配什么音效

每个音效都要对应一个画面动作，没有动作就不加。

| 画面动作 | 音效 | 响度（峰值 dBFS） | 备注 |
|---|---|---|---|
| 徽章、标签、数据弹出 | pop | -9 ~ -16 | 连续几个依次弹出时，每个间隔 0.18~0.28 秒，越往后越轻 |
| 卡片甩进、面板入场 | whoosh_swipe | -9 ~ -14 | 三个面板依次入场，就三声，间隔同入场间隔 |
| 镜头推近、焦点换到某个面板 | whoosh_low | -11 ~ -13 | 截 0.9 秒，提前 0.1 秒 |
| 整段转场、大元素入场 | whoosh_deep | -8 ~ -13 | 截 1.0~1.4 秒，提前 0.2~0.3 秒 |
| 细节放大（推到某一处） | whoosh_swipe | -17 ~ -19 | 很轻，只是提示 |
| 大标题、VS、揭晓、关键台词 | impact / hit_bay / boom | -6 ~ -10 | 和画面重击同一帧；音乐在这一帧前让位（DIP） |
| 获胜、金句、数字涨满 | sparkle_star | -12 ~ -17 | 截 1.2~1.5 秒，跟在重击后 0.05 秒 |
| 蓄力、升级、「要换歌了」 | riser_short | -13 ~ -15 | `align='end'`：结尾对齐落点 |
| 第一名、盖章认证 | stamp | -8 | |
| 失败、看不到、出 bug | error | -14 ~ -18 | 截 0.6~0.9 秒 |
| 键位反了、不对 | buzzer | -16 ~ -18 | 只用于明确的「操作错了」；「拿不到 / 做不到 / 不推荐」用下一行 |
| 拿不到、做不到、失效（元素变灰裂开） | crash_toy（截 0.5 秒） | -19 | 轻碎裂声；以后能从 Freesound 下载时可换成更细的 crack 音效 |
| 掉到最后、退赛 | slide_down | -10 ~ -11 | 喜剧感 |
| 反转、尴尬、回放 | scratch | -6 ~ -15 | 反转时重（-6），回放提示时轻（-15，截 0.5 秒） |
| 花了多少钱 | cash / coin | -12 ~ -14 | |
| 撞车、彻底失败 | crash | -8 | 同时让音乐停 |
| 教程点击 | （不加） | — | 阿亮：教程录屏不需要鼠标点击声（2026-10-22） |
| 打字 | typing | -16 ~ -18 | 截成和打字动画一样长 |
| 倒计时 | drumroll + tick | -16 / -10 | 鼓滚提前 1.75 秒，每秒一声 tick（截 0.25 秒） |
| 闪电、VS 电流 | zap / zap_short | -24 ~ -27 / -20 | 持续的电流声要很轻（阿亮：「轻微」） |
| 想法、好主意、通过 | ding | -12 ~ -13 | |
| 几张纸片 / 截图依次飞入（2026-10 鹈鹕测试重剪） | whoosh_swipe × 张数 | -13 起每张轻 1 dB | 间隔和入场间隔一样（0.45 秒）；第一张前再垫一个 whoosh_deep（提前 0.25 秒） |
| 戳破、炸开 | whoosh_cartoon + hit_bay + pop_cartoon | -14 / -10 / -9 | whoosh 提前 0.7 秒冲过来；hit 用 `align='peak'` 对齐戳破那一帧 |
| 窗口被甩飞、撞击 | hit_bay | -15 | `align='peak'`，截 1.2 秒 |
| 梗视频结尾花屏 | static + bleep | -14 / -16 | 同一帧；音乐在前面已经刮停 |
| 换到新段落 | riser_short | -16 | `align='end'`，结尾对齐新段落第一帧 |
| 一组徽章环绕弹出 | pop × 个数 | -14 起依次轻 0.25 dB | 间隔 0.06~0.1 秒，太密时隔一个放一个 |

## 四、用法细节

- **音效先峰值归一，再按表里的 dB 放**（`mix.py` 已经这样做），不同素材的原始响度差异不会影响。
- 对齐方式：`start` 开头对齐（默认）；`end` 结尾对齐（riser）；`peak` 最响处对齐（有前摇的重击）。
- 长音效用 `dur` 截短，末尾自动 50 ms 淡出。
- **不要叠太多**：同一时刻最多两层（例如 impact + sparkle）。阿亮那期要求删掉了 18 秒附近一组 riser + hit + lightning，因为太吵、和画面不匹配。
- 同一类动作全片用同一个音效，观众会形成条件反射（焦点切换永远是 whoosh_low，弹出永远是 pop）。
