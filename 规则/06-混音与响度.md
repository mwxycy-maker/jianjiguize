# 06 混音与响度

来源：DeepSeek 三模型 PK 那期（2026-10）。脚本：[工具/mix.py](../工具/mix.py)，配乐表和音效表写在 `cues.py`（例子见 [工具/示例_cues.py](../工具/示例_cues.py)）。

## 参数

| 项 | 值 | 说明 |
|---|---|---|
| 采样率 | 48 kHz 立体声 | |
| 人声 | -16 LUFS | 按时间线拼接后整体归一；每个剪点两端 12 ms 淡入淡出，避免咔哒声 |
| 音乐 | 每首 -17 ~ -21 LUFS | 按每首歌的参考段（`ref_ss` 起 `ref_dur` 秒）测响度再定增益，不同歌之间不会忽大忽小 |
| 说话时音乐闪避 | -11 dB | 起声 60 ms、释放 350 ms；说话检测用人声包络的 35% 分位 × 0.5 做阈值 |
| 重击前让位（DIP） | 前 0.12 秒压到 10% | 让重击更响、更干净 |
| 音乐停止 | 混响尾巴 0.8~1.8 秒 | 截断处最后 0.35 秒卷积指数衰减噪声 |
| 音效 | 峰值归一后放到 -6 ~ -27 dBFS | 见 04 |
| 整片 | -14 LUFS，真峰值 -1 dBTP，LRA 11 | ffmpeg `loudnorm` 两遍（先测再线性归一） |
| 结尾 | 最后 0.8 秒淡出 | |
| 输出 | mix.wav（16 bit）+ mix.m4a（AAC 160k） | 网页预览用 m4a；发布到 artifact 时转 mp3 |

## 习惯

- 改了配乐表、音效表或口播时间线，**一定要重新混一遍**，再打包预览（混音文件比 cues.py 旧就是过期了）。
- 混完看一眼输出的三路响度：人声应在 -16 左右，音乐比人声低 6~9 LU，音效比人声低 5~8 LU。
- 画面里的视频永远静音，声音只走混音这一路，避免和混音里的同一段声音打架。
- 混音放后台低优先级跑（`nice`），不拖慢同时在跑的录制任务。
