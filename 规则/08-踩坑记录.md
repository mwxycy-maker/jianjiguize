# 08 踩坑记录

来源：DeepSeek 三模型 PK 那期（2026-10）。按「现象 → 原因 → 解决」记。

## 录制

| 现象 | 原因 | 解决 |
|---|---|---|
| `run_for` 报错 | 参数必须是整数毫秒 | `int(round(frame * 1000 / fps))` 再相减 |
| 游戏倒计时卡住不动 | `clock.install` 之后时间仍会自然流动 | 装完立刻 `pause_at`，之后只靠 `run_for` 推进 |
| 雷峰塔的机位乱跳 | 抓到了水面反射相机；网页自己的镜头动画覆盖了我们的摆位 | 用 `cam` 表达式指定主相机；锁住相机的 position / quaternion / lookAt |
| 录制极慢 | rAF 每秒 60 次，每次都渲染 | 时钟装好后注入按录制帧率触发的 rAF；注意必须在 `clock.install` 之后注入，用不可配置属性会卡死 |
| 网页白屏 | three.js 从 CDN 加载失败 | 本地 clone 对应 tag，路由 CDN 请求到本地 |
| `pkill -f` 把自己的 shell 也杀了 | 匹配到了自己的命令行 | 用 `'^python3 xxx'` 精确匹配，或按 PID 杀 |
| 录制排队到一半没了 | 后台任务默认 30 分钟时限 | 启动时把时限设到最长；每段录完单独检查 |
| 海岸画面中间横着一条白色波形线 | 页面另一块小画布（水位曲线）叠在场景上 | 开头用 js 动作把它设透明 |
| 加了隐藏样式后第一帧截图超时 | 用 css 配置隐藏那块画布后，预跑 5 秒再截图会卡死（短预跑又正常，原因未查明） | 改用 js 动作隐藏 |
| 游戏录像循环播放时闪一下 | 录像第 0 秒有一帧镜头复位 | 循环时跳过开头 0.6 秒 |
| **录像里偶尔闪一帧黑**（海岸：DeepSeek 3 帧、GPT 2 帧） | 截图那一刻网页画布还没画完，截到整帧黑 | 录制脚本每帧检查亮度，突然掉到很低就重截；已录好的用 [工具/fixblack.py](../工具/fixblack.py) 把黑帧换成前后帧平均。录完逐帧扫一遍亮度再用（游戏里穿门、撞车的亮度变化是正常画面，要看图确认） |
| **网页预览里画面来回抽搐、一闪一闪**（导出视频没问题） | 素材时间按 0.86、0.25 倍速推进，但取视频时没把倍速传给播放器：视频按 1 倍速跑，偏差超过 0.2 秒就被拉回去 | 取视频时把倍速一起传（`E.video(key, ts, rate)`），只要时间不是 1 倍速推进就必须传 |

## 浏览器 / 网页

| 现象 | 原因 | 解决 |
|---|---|---|
| 审片时视频是黑的 | 无头 Chromium 没有 H.264/AAC 解码 | 做 VP8/Opus 代理，本地服务把同一 URL 映射过去 |
| 「视频无法解码」报错 | 素材还没录好，键名不在素材表里 | 取视频前先判断键名在不在，不在就画占位色块 |
| 发布到 artifact 后中文乱码 | 脚本没声明编码 | `<script defer charset="utf-8">` |
| 线上预览打开就报「工程加载失败：视频定位超时」 | 播放器启动时同时预载全部视频（那期 24 个约 90MB），网慢时开头那段被挤占，15 秒内定位不到就整页失败 | 在项目自己的 preview.js 里改加载策略（只对线上生效）：不一次性预载、定位时网慢多等（最多 2 分钟）、就绪后按出场顺序后台预热 |
| **定格的素材在网页预览里「鬼畜」**（2026-10 鹈鹕测试重剪，镜 26） | 素材时间停住不动，取视频时却按默认 1 倍速：视频自己往前跑，偏差一超就被拉回去，反复跳 | 定格时传 `rate = 0`；素材放完也要停在最后一帧并传 `rate = 0`（`vid()` 已经自动处理） |
| 发布后脚本不执行 | 页面没有 body 标签时脚本执行时机不对 | 脚本加 `defer` |
| m4a 发布失败 | m4a 不在允许的文件类型里 | 转 mp3 |
| 字体文件太大 | 整套中文字体几十 MB | 用 fontTools 只取用到的字做子集（[工具/make_fonts.py](../工具/make_fonts.py)）；没有 brotli 时输出 woff |

## 网络

| 现象 | 原因 | 解决 |
|---|---|---|
| Openverse 接口 403 | Python urllib 默认 UA 被拒 | 用 curl 带浏览器 User-Agent |
| Freesound 下载偶尔失败 | CDN 限流 | 重试几次、间隔递增；检查文件大小，0 字节的要删掉重下 |
| Openverse 接口 401/失败 | 匿名请求每页超过 20 条 | `page_size` 不超过 20 |
| Freesound 下载全部 403（2026-10-23，搜索接口正常） | Freesound 音频服务器拒绝了这个云端环境的请求，加 Referer 也不行 | 先用音效库里已有的近似音效顶上，记下想换的 Freesound 编号，能下载时再换 |
| 照 earshot 网页装完，`cd: no such file or directory: earshot`、`python: command not found`、`claude mcp 添加` 报 unknown command（2026-10-24） | 复制的是浏览器自动翻译成中文后的命令：`&&` 被翻成 `和&`（仓库被克隆进了叫「和」的文件夹），`add` 被翻成 `添加`；Mac 上没有 `python` 只有 `python3`；`/path/to/earshot/` 是占位符 | 关掉网页翻译再复制，或直接用 [04-音效](04-音效.md) 里的命令；`python` 换 `python3`（要 3.10+），路径写 `"$HOME/earshot/.venv/bin/python"` |
| npm / pip 装不上 | 云端网络白名单 | three.js 用 git clone 对应 tag；能不用的依赖就不用 |

## 画面

| 现象 | 原因 | 解决 |
|---|---|---|
| 「亿」字认不出来 | 标题字体单字笔画太花 | 单位字用 Noto Sans Black |
| 主持人圆窗压住内容、字幕 | 构图没给圆窗留位置 | 内容整体往右上让，或在需要整幅时让圆窗淡出 |
| 奖牌压住了模型名字 | 奖牌放在面板右上角，正好是徽章名字的位置 | 往下挪到名字下方 |
| 数据水印超出画框 | 竖条面板窄，水印按固定字号画 | 按画框宽度自动缩字（最小 14px） |
| 一家的演示特别暗，夸它时没说服力 | 模型生成的场景本身就暗 | 合成时只给这一家加亮度/对比度滤镜 |
| 从演示切回口播时有半秒空画面 | 演示先退场，头像等下一镜才开始放大 | 退场和放大重叠进行 |
| 竖条里的长徽章名伸出画框 | 30px 字号对 440 宽的竖条太大 | 竖条里用 26px |
| 文字特写改成杂志风后字看不清 | 小字截图放大 + 透视 + 反白后发糊 | 回到原方案：截图原样 + 半透明高亮条 |

## 导出与性能（2026-10 鹈鹕测试重剪）

| 现象 | 原因 | 解决 |
|---|---|---|
| 浏览器逐帧导出 2 分钟才 60 帧 | 云端无 GPU，软件渲染下 `ctx.filter = 'blur()'`、每帧全屏渐变、网点合成都很贵（单帧 0.37 秒） | 静态背景画一次缓存成画布；虚化改成「缩小 1/4 画进离屏画布再平滑放大」；单帧降到 0.05 秒 |
| 公共导出器启动失败 | `export_mp4.py` 指定 `channel='chrome'`，云端只有 Playwright 自带 Chromium（也不解 H.264） | 临时副本去掉 channel，素材走 VP8 审片代理（`工具/proxies.py`）；音轨直接用 mix.wav |
| 2 核机器导出整片 | 6000 多帧单进程四五十分钟 | 按时间分两段并行（`--start/--duration`），再拼接、整轨重新铺音频 |
| 预览包里少图 | `preview_build.py` 按文件名在代码里搜索，模板字符串拼的名字（`OK4_${k}`）搜不到 | 场景里写完整文件名数组 |
| 鼓点对不上 | beats.py 旧版响度表时间标签漂移 | 用新版 `onsets()` 的起音实测值 |
