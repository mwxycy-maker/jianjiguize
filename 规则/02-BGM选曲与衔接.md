# 02 BGM 选曲与衔接

来源：阿亮提供的《音乐衔接教程》+ DeepSeek 三模型 PK 那期实操（2026-10）。

## 一、选曲

1. **开头用阿亮指定的那首**，后面按段落换歌。一首歌不要拖过好几个段落；画面换到新段落，BGM 也换。
2. **按段落情绪挑歌**：

   | 段落类型 | 要的感觉 | 用过的 |
   |---|---|---|
   | 开场、VS 对决 | 有冲击、有一记大鼓能卡重击 | Pow（William Baxter Noon） |
   | 揭晓结果、比赛感 | 明快、往前冲 | Let's Win This（BalloonPlanet） |
   | 3D 建模等动画演示 | 电子、有劲、不抢人声 | Challengers |
   | 轻松的演示、内心戏 | 明亮、轻 | Young Dumb & Broke（Instrumental） |
   | 赛车、竞速 | 高潮段、速度感 | Forwe - Sole Viola 的高潮（阿亮指定） |
   | 教程讲解 | 稳、钢琴、不打扰 | Heard 'Em Say（Instrumental） |
   | 收尾 | 轻快、能带走 | Does It for Me（Where's LuLu） |
   | 人物登场（介绍某个人） | 复古摇滚、有态度 | It Came Out Of The Sky（只用前奏 + 吉他独奏），鹈鹕测试那期 |
   | 插完梗回到正题 | 轻松、往前走 | Live in the Moment（Instrumental），从 drop 进 |
   | 揭穿、拆台、一条条推进 | 拍手跺脚、节奏感强 | Modern Urban Claps and Stomps |

3. **空灵、氛围感的音乐只放在没有人出镜的空镜里**；主播出镜时用轻快的叙事配乐。
4. **歌不够时可以复用**，优先复用开头那几首（首尾呼应）。那期 Pow 在开场和「愿称梁圣为最强」各用了一次，同一记大鼓砸两次，观众会有呼应感。
5. **音频文件放在当期视频仓库**（阿亮有版权），例如 [DeepSeekv1-flash/剪辑工程/音乐](https://github.com/mwxycy-maker/DeepSeekv1-flash/tree/main/剪辑工程/音乐)；鹈鹕测试那期的在 [pelican-test/重剪工程/音乐](https://github.com/mwxycy-maker/pelican-test/tree/main/重剪工程/音乐)。下一期复用时从那里拷进新工程的 `音乐/`。每首歌的可用起点记在下面的曲库笔记里。
6. **有人声的歌不要垫在口播下面**：先用识别模型扫一遍（SenseVoice 对英文歌词也能出字），找出前奏、间奏、尾奏这些没人声的段，强拍对强拍拼起来用（2026-10 鹈鹕测试重剪）。
7. **一首歌只撑一个话题**：人物登场的配乐只撑这个人物的介绍，话题一转（插完梗、回到正题）就换歌。阿亮（2026-10 鹈鹕测试重剪）：「16 号镜头开始的 BGM 太响了，而且太长了，22 号开始换新的 bgm」。改完 It Came Out Of The Sky 只用 20 秒（镜 16–21），镜 22 起换 Live in the Moment。
8. **中高频密集的段要放低**：吉他独奏、摇滚这类声音和人声抢同一个频段，比普通讲解配乐再低 2 dB（那期 -21 LUFS，其他段 -17 ~ -19）。

## 二、衔接：停止 + 转移注意力 + 开始

教程的核心公式。上一首怎么停、中间用什么接住、下一首从哪进来，三件事都要设计。

### 1. 上一首怎么停

| 停法 | 什么时候用 | 实现 |
|---|---|---|
| **混响尾巴** | 默认；段落正常结束 | `mix.py` 的 `tail`：截断处卷积一段指数衰减噪声，1~1.8 秒自然消失 |
| **重击后停** | 大标题、VS、揭晓 | 音乐在重击那一帧停，`DIP` 在重击前 0.12 秒把音乐压到 10%，让重击更响 |
| **唱片刮停** | 反转、尴尬、笑点（「万万没想到」「余额用尽了」） | 音乐 `fade_out=.06` 硬停 + `scratch` 音效，然后留空让笑点落地 |
| **撞车/碎裂声接** | 画面里有失败、撞墙 | 音乐在撞击帧停，撞击音效接住 |

### 2. 中间用什么接住注意力

- 一句台词、一个转场音效（whoosh）、一个明显的画面切换，三选一或叠加。
- **切割按钮**：用上升音效（riser）提示「要换歌了」，riser 的**结尾**对齐新段落第一帧（音效表里 `align='end'`）。
- 高潮前可以故意把音乐切掉、留空半秒，再让下一段炸开。

### 3. 下一首从哪进来

- **从强拍或段落起点进来**，不要从一首歌的随便哪一秒开始。用 `工具/beats.py` 找强拍：
  ```
  python3 工具/beats.py "音乐/xxx.mp3" 0 90
  ```
  输出 BPM、强拍时间、每 0.5 秒的响度，以及「空拍后的重击」起音点（逐 25ms 实测）。**卡重击一律用最后这一项**：0.5 秒的响度表只适合看大致段落。
  （2026-10 鹈鹕测试重剪：旧版 beats.py 的响度表每格实际 0.4876 秒却按 0.5 秒标时间，48 秒处偏了 1.2 秒，已修正。）
- 进来的淡入要短（0.02~0.4 秒）。从强拍进来时淡入越短越有力。
- **让歌里自带的鼓点去砸画面重点**。算法是倒推起点：
  ```python
  # 曲子 28.95 秒有一记大鼓，要让它落在成片 VS_SLAM 这一帧
  src = 28.95 - (VS_SLAM - 歌曲进入时刻)
  ```
  那期每一首都这样对过：Pow 的大鼓对 VS 重击和「最强」，Sole Viola 64 秒的 drop 对第一款游戏出现，Challengers 7.895 秒的强拍对三座塔入场，Does It for Me 40 秒处的停顿对「那就是拉」。

### 3.5 安静前奏的歌：从 drop 进

前奏很长、很安静的歌（Live in the Moment 前 15.6 秒几乎只有铺底），不要从 0 秒放。直接从节奏进来那一拍（drop）进，并让 drop 对准画面「回来」的那一刻（花屏结束、回到主播），音乐和画面一起起来。

```python
dict(file='音乐/moment.mp3', src=15.652, at=EV['back'], ...)   # 15.652 秒是 drop
```

### 3.6 插梗的一整条衔接链（2026-10 鹈鹕测试重剪，可整段照搬）

```
上一首（Sky）唱片刮停 scratch，音乐 fade_out .06 硬停
→ 梗视频原声满音量（duck=False，只留最有梗的 2.6 秒）
→ 0.5 秒电视花屏 + 哔声（static + bleep，各 -14 / -16）
→ 开机线展开回到全屏主播（0.28 秒）
→ 新歌（Moment）从 drop 进，fade_in .02
```

停止（刮停）+ 转移注意力（梗视频和花屏）+ 开始（drop）三件事都在里面，前后两首歌完全不同也不突兀。

### 3.7 同一首歌复用：再卡一遍它的两记大鼓

Pow 在开场用过一次后，③ 后半复用时不要接着上次的位置放，而是重新倒推起点，让同样的 28.95 秒和 48.45 秒两记大鼓再落在后半段的两个重点上（那期落在「作为公开的题库」和「现在主流的操作则是跑动画」）。观众听到熟悉的鼓点，会有首尾呼应感。

### 3.8 空拍回归的歌：每个重拍都是一个卡点

Claps and Stomps 这种每 6.8 秒留一个空拍、然后重拍回归的歌，回归点就是现成的卡点：倒推起点，让其中一个回归落在本段最重要的动作上（那期是「戳破虚假泡泡」），下一个回归自然落在 6.8 秒后的新画面（六宫格出现），段尾再用唱片刮停收。

### 4. 情绪相近的两首

可以直接交叉过渡，但要把第二首的鼓点对齐第一首，声音不要断。BPM 差太多时只做小幅变速，变太多细节会丢。

### 5. 别过度

技巧太多反而不自然。不是每次换歌都要 riser + 刮碟 + 留空，一段一种手法就够了。

## 三、口播时音乐怎么让路

- 音乐整体响度按 -17 ~ -21 LUFS 的参考值放进去（讲解段低一点，演示段高一点）。
- **说话时自动闪避 -11 dB**：起声 60 ms、释放 350 ms。口播一停音乐就抬起来，口播一开口音乐马上让开。
- 口播空档里需要满音量的段落（例如 MV 完整播放），那一条关掉闪避（`duck=False`）。
- 演示里自带原声（比如 AI 生成的视频）可以当背景音用，但人声说话时画面里的视频要**静音播放**，只留混音里那一路。

## 四、可直接复用的配乐表写法

配乐表里每一首歌一行，所有时间都引用事件名，口播一改就自动跟着走。完整例子见 [工具/示例_cues.py](../工具/示例_cues.py)。

```python
dict(file=SOLE,                          # 哪首
     src=64.0 - (EV['g1'] - EV['sec7']), # 从歌的第几秒开始：让 64.0 秒的 drop 落在 g1
     at=EV['sec7'],                      # 成片第几秒进
     until=EV['crash'] + .02,            # 成片第几秒停
     level=-18,                          # 目标响度（按 ref_ss 起的 ref_dur 秒测）
     fade_in=.04, tail=.8,               # 淡入；混响尾巴
     ref_ss=64, ref_dur=30)
```
