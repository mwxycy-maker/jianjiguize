# 03 动效与构图

来源：DeepSeek 三模型 PK 那期，差评君的动画效果配秋芝的人像出场方式；阿亮两轮反馈（2026-10）。鹈鹕测试重剪那期（2026-10）补充了六之二、七之二、十二。
组件代码在 [组件/动效组件.js](../组件/动效组件.js)，三联面板的完整用法在 [组件/示例_三联面板.js](../组件/示例_三联面板.js)；鹈鹕测试那期的组件在 [组件/鹈鹕测试组件.js](../组件/鹈鹕测试组件.js)，镜头写法在 [组件/示例_镜头接力与新闻散开.js](../组件/示例_镜头接力与新闻散开.js)。

## 一、底层原则

1. **动画是时间的纯函数**：每一帧只由 `t` 决定（`renderAt(t)`），不存状态、不靠上一帧。这样可以任意拖进度条、逐帧导出、反复改时间而不出错。
2. **所有时间都挂在口播事件上**：事件名 = 第几句 + 哪个词（`A(8, '整体效果')`），口播一改、停顿一压缩，画面自动跟着走。不要手写秒数。
3. **快进慢停**：入场用强缓出（`easeOut` 4 次方），出场用缓入（`easeIn` 2~2.4 次方），位置变化用三次缓入缓出（`eInOut`）。弹性只给徽章、奖牌这种小元素（`backOut` 1.6~2.2）。
4. **时长参考**：入场 0.55~0.75 秒，退场 0.3~0.55 秒，重新构图 0.6~0.7 秒，徽章弹出 0.45 秒，大标题砸下 0.32 秒。比这更慢会拖，更快会生硬。

5. **写场景时就顾着性能**（2026-10 鹈鹕测试重剪）：静态背景（渐变 + 网点）画一次缓存成画布；虚化不用 `ctx.filter = 'blur()'`，改成「缩小画进离屏画布再平滑放大」（`win()` 的 `blur` 参数就是这样做的）。云端软件渲染下单帧从 0.37 秒降到 0.05 秒。

## 二、横屏一致感（阿亮反复强调）

在 HTML 演示时，一定要让观众感觉「我们是在横屏里看一组东西」：

- **同一组演示，角度一致、运动方向一致、出场时间一致。** 三座塔用同一个机位（仰角 10°、视场角 35°）、同一个转速（每秒 6°）；三家便利店同样（仰角 26°、起始方位 35°）。录制时用环绕相机统一摆位，见 07。
- **大小一致**：模型做出来的东西本身大小不一，合成时按各自占比补一个基础放大（`TOWER_BASE`、`STORE_BASE`），让三者在画面里一样大。
- **从左到右依次入场，间隔 0.5 秒**。三个面板的左右顺序全片保持一致（那期是 GPT、Opus、DeepSeek），观众不用每次重新找。
- **同一组的退场也错开**，间隔 0.08 秒，比入场快。
- 素材播放速率三者一致（`TOWER_RATE`），保证任何时刻三者的旋转角度一样。

## 三、画幅：要大

阿亮原话：「画面的框太小了，要扩张到绿框左右大小」「争取把画面上下铺满」。

- 单个演示窗口宽度不小于画面的 **85%**（1920 宽的画面里 1640 左右，例如 1640×922）。
- 三个并列的视频要**上下铺满**：不改变视频比例的前提下，把画幅做宽（那期 MV 三联：每条 1000×346，纵向 180 / 540 / 900 排满）。
- 数据水印要跟着画框缩字，不能溢出画框（`dataMark` 已经处理：超宽自动缩小，最小 14px）。
- 竖条面板（440 宽）里的徽章名字用 26px，长名字（DeepSeek V4.1 Flash）30px 会伸出画框。
- 画面让位给提示词卡等元素时，缩小不要超过 0.86 倍；同时检查画面底边离字幕至少 40px。

## 四、构图：注重当下，出现新元素再重排

阿亮原话：「演示部分更注重当下，当出现其他元素，再重新构图即可」。

- **演示刚出来时居中、最大**，只有它自己。
- **有新元素（倒计时、数据表、徽章、提示词卡）要出现时，原来的画面平滑让位**：往一侧挪、缩小，0.6~0.7 秒缓入缓出。例：MV 三联先在正中（cx 990，缩放 1），揭晓时挪到 cx 740、缩到 0.8，数据出现时再挪到 cx 690、缩到 0.7。
- 新元素撤掉后，画面可以回到居中放大。
- **点到谁，谁上前**：口播说到某个模型时，它的面板移到画面中央放大（1.2~1.5 倍），其余面板**模糊 + 压暗 38%** 退到后景。说完再归位。
- **细节放大跟着口播走**：说到「水面」就推到水面，说到「山」就推到山。用关键帧插值 `keyed()`，每个关键帧之间 0.55~0.7 秒过渡，焦点 `(fx, fy)` 按素材里的实际位置定。

## 五、3D 视角：少用

阿亮原话：「从这里之后的大多数案例，都不需要有 3D 摄像机视角了」。

- **开场的任务卡**可以用差评君式 3D 飞入（`flyPose`：从右下远处小而倾斜地飞来，减速落位）。
- **演示部分默认平面进出场**（`flatPose`：从 0.88 倍、下方 70px 处轻微放大上浮淡入；`flatExit`：缩到 0.9、下沉 60px 淡出）。
- 需要一点冲击时，可以给极轻的 3D 推进（例：赛车段每款游戏入场带一点透视），但不要倾斜到看不清内容。

## 六、差评君风格要素

- **窗口卡片**：粗黑边（9px）+ 白色内框（14px）+ 大圆角（30px），里面放视频或截图，带投影。
- **背景**：浅灰径向渐变 + 网点 + 两团缓慢漂移的柔光（`bgLight`），不要纯色平涂。暗场用 `bgDark`。
- **大标题**：单独出现，从 1.9 倍砸到 1 倍（0.32 秒），落地后 0.35 秒内抖动，配重击音效；描边 14% 字号，带投影。
- **截图特写**：截图斜放或平放，用高亮条（半透明 0.5）扫过要强调的那行字，外面压暗。
- **文字片段特写，字清楚优先**（2026-10-22 阿亮反馈）：试过「整页纸斜放 + 后景虚化纸页 + 整行色块反白」的杂志风，阿亮看完说「字有点看不清了，还是改成原方案」。截图里的字本来就小，放大加透视后边缘发虚、反白后更糊。结论：文字特写保持截图原样（原色、轻微倾斜），只用半透明高亮条扫过，不做反白、不转黑白、不铺满整屏。
- **点击效果**：教程类录屏剪成跳切（每切一下闪一帧白），镜头推到要点的按钮，加一个点击涟漪。

## 七、秋芝风格的人像

- **全屏口播 ↔ 左下角圆形头像**：同一个画面连续变形（圆角矩形一路收缩成圆），源画面的裁切也同时从整帧过渡到脸部正方形。0.75 秒左右，缓入缓出。不要硬切成小窗。
- 圆窗：圆心 (196, 870)，半径 138（1920×1080 画面），白色 8px 描边 + 外圈品牌色 3px 细环，带投影。
- 圆窗放在空角上，不挡内容；画面需要整幅时（例如大对比图）可以让圆窗淡出。
- **从圆窗回到全屏时，不能留空画面**：演示画面退场和头像放大要重叠进行（头像在画面退场前约 0.45 秒就开始放大），不要等画面完全退完再放大，否则中间会有半秒左右只剩背景和小圆窗。
- 不从全屏变形时，圆窗用弹出（`hostPop`，`backOut` 1.6）。
- **用一条「主播状态轨」管全片**（2026-10 鹈鹕测试重剪）：`[时刻, 'full' | 'circle' | 'none']` 一张表，帧合成时按它决定先画全屏口播还是先画场景再叠圆窗。变回全屏的变形提前 0.7 秒开始（在上一镜内容上完成），变成圆窗的变形在新镜开始时进行。画面需要整幅（六宫格、新闻散开）时设 `none`。
- 两次全屏之间不到 1 秒的，不要来回变形，保持圆窗。
- **状态之间怎么过渡**：全屏 ↔ 圆窗是 0.75 秒连续变形；圆窗弹入 0.5 秒（`backOut 1.6`）、收起 0.35 秒；`none` ↔ 全屏是**硬切**。阿亮（镜 42）：「直接硬切全屏 Aroll，出画时再正常缩小」，也就是从整幅画面切回口播用硬切，离开口播时照常变形成圆窗。
- **画面自己有人物、头像时不出圆窗**：阿亮（镜 41，发明者呼吁别给模型排名）：「41 号镜头，没有 aroll」。画面里已经有一个人的头像时，主播圆窗会和它抢，设 `none`。
- 每次回到全屏口播，画面从 1.0 缓慢推到 1.05（6 秒），口播段不会显得死。

## 七之二、新闻截图散开（2026-10 鹈鹕测试重剪，阿亮给的参考）

- 暗场里几张新闻截图像纸一样依次从下方翻上来（透视 + 旋转，0.7 秒强缓出），后一张到了，前一张往两边散开。
- 每张落定 0.5 秒后，黄色马克笔（multiply）扫过标题里的关键词；最后一张的关键词最大，镜头推过去放大到能在手机上看清。
- 纸片不加黑框窗口，就是白纸 + 投影；不出主播圆窗。
- 参数：三张间隔 0.45 秒；纸片从 0.55 倍、下方 520px、前倾 38° 翻上来；下一张到时前一张 0.7 秒散到两侧；整体 2.6 秒内慢推 4%，最后一张关键词划亮后 0.9 秒推到 1.42 倍对准关键词。用 `newsPaper()`。

## 八、花字和数字

- **大数字跟着口播涨**：从 0 涨到目标值，涨的节奏和念数字的时间同步（「5 亿」念完，数字刚好涨满）。用缓出（`1-(1-r)^2.2`），越接近终点越慢。
- **涨满后停一会儿再走**（阿亮：「稍微停留一下，不要直接消失，观众会反应不过来」）。涨满时放大 8% 再弹回，停留至少 1 秒；退场时上移 40px 淡出。
- **字放在人物后面**：背景先压暗 50%，画巨字，再把抠好的人物盖回去，形成前后层次。字体用粗黑体，数字用 Bebas Neue 这类窄体，字号要大（数字 360px、单位 230px）。
- 中文花字避免用笔画太花的标题字体做单字（那期「亿」用优设标题黑认不出来，换成 Noto Sans Black）。

## 八之二、连线、花字和人物的前后关系

- **从人物身前横穿的连线、花字，要放到人后面**（阿亮 2026-10-22：「连的虚线放在人后面」）。做法：先画线/字，再用抠像人物层盖回去；两端的徽章仍放在人前面（它们在两侧，不挡人）。
- 每个需要「字在人后」的口播片段都单独抠一段人像（[工具/matte.py](../工具/matte.py)，8 秒约半分钟），不要拿别的时间段的抠像凑。

## 九、徽章

- 白色圆底 + logo + 品牌色细描边 + 名字（粗黑体，深色描边保证任何背景都能看清）。
- 出现用弹性（`backOut` 2.2，0.45 秒），悬停时轻微上下浮动。
- 状态变化要有动作：退赛的模型徽章变灰、下落；升级的模型加一圈光环和闪光；获胜的给金色奖牌（带「1」，轻微摇摆）。
- 奖牌、角标不能压住徽章上的名字。

## 十一、文字特写与录屏（2026-10-22 阿亮反馈）

- **重点句子的高亮一开始就标到位**：卡片出现后就慢慢把整句（从第一个关键词到句末）都扫上颜色，不要跟着字幕一个词一个词地追；扫得慢一点（一行 1.2–1.5 秒）。
- **高亮条和字上下居中**：按截图里字的实际像素上下边界算，上下各留约 0.3 个字高。
- **截图特写要让每一行左右完整可见**：宁可整页缩小也不要把行首行尾裁掉；页面尽量占满画面，这时左下角头像可以淡出，镜头结束前再淡回来。
- **不需要强调的行不要标**（例如「已完成，用时 xx」这类状态行）。
- **录屏跳切不加白闪**，「一闪一闪」很打扰。
- **运镜不要太快**：推近、平移的过渡至少 0.7 秒；如果推近效果不好，就干脆不推近，只用高亮框。
- **高亮框必须逐个对着素材帧核对**：截出每个切点后 0.35 秒和 1.2 秒的素材帧，把框画上去看；对不上的去掉，界面随后变化的（下拉框关闭等）让框提前消失。
- **口播先行**：一段讲解的开头还没讲到操作时，先用纯口播，说到「配置起来也非常简单」这类话时再进录屏。例：「没有安装的同学，可以直接去官网下载一下，非常简单」全程 A-roll，说到「这里有两种接入方式」才进录屏；相邻两镜都是口播时，中间不要缩成圆窗再放大。
- **教程录屏不加鼠标点击声**。
- **关键页面停留要够**：文字特写至少停留 4 秒左右，可以延续到下一句口播说完再切走。

## 十、演示视频的播放规则

- **人物说话时，画面里的演示视频照常播放（静音）**。不要定格，观众要看到东西在动。
- 演示视频的出现时刻 = 开始播放时刻，三个依次出现就依次开始（间隔 0.16 秒左右）。
- 需要「回放」时（例如「GPT 是凭空出现的」），对应面板从 0 秒重播，开头加 0.2 秒倒带故障效果提示。
- **先定格、说到再播**：口播还没说到「动起来」时，素材停在第 0.2 秒；说到那个词才开始播放。定格时取视频一定要传 `rate = 0`，否则网页预览会来回跳（阿亮：「26 号素材开头鬼畜了」，见 08）。
- **素材放完停在最后一帧**：素材比镜头短时，`vid()` 自动停在最后一帧（`rate = 0`），不要让它循环或黑掉。

## 十二、镜头接力、全屏素材和收尾（2026-10 鹈鹕测试重剪）

示例代码：[组件/示例_镜头接力与新闻散开.js](../组件/示例_镜头接力与新闻散开.js)。

### 1. 镜头接力：上一镜退场和下一镜进场重叠

- 每个镜头的画法写成 `drawX(ctx, t, b)`，自带退场时刻 `b`；`VIS[k] = 背景 + 上一镜 drawPrev(t, 本镜进场 - 0.05) + 本镜 drawCur(t)`。
- 上一镜退场（0.45 秒）和本镜进场（0.65 秒）重叠，画面永远不会有空帧，任意拖进度条也对。
- 同一组卡片的入场间隔：新闻纸片 0.45 秒；2×2 四宫格 0.18 秒；斜着飞入的一排 0.15 秒（`fromX 260`、`fromRot 14`）；退场间隔 0.04~0.06 秒。

### 2. 素材本身信息量大：全屏播放，不套窗口

阿亮：「28 号镜头，里面的视频全屏播放」「49 号空镜全屏播放」。

- 发布会、背题这类本身就很满的视频，直接铺满全屏：入场 0.35 秒从 1.08 倍缩到 1（强缓出），之后整个镜头缓慢推进 3~4%；退场 0.35 秒淡出。
- 要在上面叠数字、印章时，先把视频压暗 25~45%，叠的东西才看得清。
- 这段主播状态设 `none`。

### 3. 点到谁谁上前：顺序以素材内容为准

镜 6 两张图，口播先讲「脚不动轮子动」再讲「脚动轮子不动」，对应的是右图再左图。阿亮：「这两张图匹配反了，先演示右侧的图，然后再演示左侧的图」。上前的顺序要先看素材里哪张图演示的是哪句话，不能默认从左到右。被压暗的画在下面，上前的画在上面。

### 4. 鼓点驱动画面

- 歌里的大鼓落在某个窗口上时，窗口额外放大 5%，按 `exp(-9t)` 衰减（0.3 秒内回落），像被鼓顶了一下。
- 鼓点时刻和配乐表共用同一个常量（例如 `POW_SRC`），换起点时画面自动跟着走。
- 撞击、失败时窗口抖动：水平 ±13px、垂直 ±9px 随机，0.35 秒衰减到 0。

### 5. 时间变迁：当前的居中放大，之前的缩到一边

「两年前只能画一张图 → 现在跑动画 → 3D」：当前的那一张在中间放大 1.12 倍；之前的缩到左边 0.5~0.55 倍，压暗 35~45%、轻微虚化，越早的越靠下、越暗。一眼就能看出是一条时间线。

### 6. 梗视频：复古电视窗 + 花屏 + 开机线

- 梗视频放进黑底窗口，加扫描线和暗角，只留最有梗的 2.6 秒（那期只留了「篮球和鸡」的特写）。
- 结尾 0.5 秒花屏：低分辨率随机灰度块放大 + 彩条错位，配 static + bleep。
- 回到主播用开机线：画面中间一道白线，上下展开成全屏口播（0.28 秒）。音乐怎么接见 [02](02-BGM选曲与衔接.md) 3.6。

### 7. 装饰元素跟着口播出现

- 镜头一开始不要摆装饰性的小圈、小标记。阿亮（镜 26）：「去掉最开始的黄色和蓝色的小圈」。
- 提示圈只在口播说到那个部位时画出来（「鸟怎么坐」→ 黄圈，「脚蹬怎么蹬」→ 红圈），说完就换下一个。

### 8. 收尾正常结束

阿亮：「55 号镜头正常结束，不用黑屏」。最后一镜不加淡出黑场，停在主播和评论气泡上。
