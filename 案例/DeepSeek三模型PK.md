## 开工前确认的事（阿亮的答复）

1. 数据都在文档里（每个案例的用时 / Token / 金额）。
2. 素材已提交。
3. WorkBuddy、Kimi Code 只用名字徽章。
4. 口播素材 480p 没关系，正常做。
5. **字幕以实际说出的为主。**
6. 眩晕片段的原声当背景音。
7. **不按工作台规矩第 12 条处理**：DeepSeek 是主角，可以出现在画面上。
8. 超过 0.5 秒的停顿可以剪。
9. MV 播放时用 `01-纸月亮_MV_1080p` 的原声。
10. **文档里的数据标注到对应的演示案例上，做成小水印**（工作台规矩「严禁小字」在这里是例外：阿亮明确要的数据水印）。
11. 音效用 Openverse（来源 Freesound）。
12. BGM 衔接参考阿亮给的教程。

## 经验

- 开工前一次问清楚，比做完再改省事得多。
- 先交两段定方向。第一轮反馈里关于画幅、构图、3D 视角的要求，后面所有段落都适用。
- 三家对比的演示，统一机位是最花时间也最值得的一步，观众一眼就能比出高下。
- HTML 录制在云端很慢，要尽早开始、后台排队，边录边做别的段落。
