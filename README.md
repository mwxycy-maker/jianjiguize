# 剪辑规则

沉淀各种剪辑准则。每做完一期，把这期验证过的做法、阿亮的反馈和踩过的坑整理进来，下一期直接照着用。

第一批内容来自「DeepSeek V4.1 Flash vs GPT-6.1 Sol vs Claude Opus 5.5」三模型 PK 那期（2026-10）。那期用网页（HTML + Canvas）剪，差评君的动画效果配秋芝的人像出场方式。第二批来自「鹈鹕测试」重剪（2026-10）：整套新视觉、主播状态轨、插梗的配乐衔接链、全屏素材的用法。

## 目录

```
规则/        一条条可以直接照做的规则，每条都写了为什么
工具/        可复用脚本（转写、时间线、混音、节拍分析、HTML 录制、找音效、审片截图……）
HyperFrames模板/  动画片段的默认做法：HyperFrames（HTML + GSAP → MP4/透明 WebM），云端环境脚本和示例
组件/        网页动效组件（差评君窗口卡片、秋芝圆形头像、徽章、大标题、数字滚动、数据水印、教程录屏、线上预览加载）
```

## 和 video-workbench 的关系

[AndroidOne-io/video-workbench](https://github.com/AndroidOne-io/video-workbench) 是公共工作台，里面有播放器引擎、风格库、字体和通用规矩。这里是阿亮自己的规则库，补充工作台里还没有的东西，以及阿亮的个人偏好。两边冲突时，以阿亮在当期给的要求为准，其次是这里，最后是工作台。

## 维护约定

- 新规则写进对应的 `规则/*.md`，标上来源（哪一期、谁提的）和日期。
- 阿亮的反馈同样的要求出现第二次，就升级成 `规则/` 里的通用规则。
- 阿亮有本期所用音乐的版权，音频文件放在当期视频仓库里（例：[DeepSeekv1-flash/剪辑工程/音乐](https://github.com/mwxycy-maker/DeepSeekv1-flash/tree/main/剪辑工程/音乐)），这里记曲名、情绪、可用起点和衔接方法。音效只放 CC0 或 CC BY 的，并在来源表登记。
